# CodeAlpha Task 1: Language Translation Tool

A Python-based language translation application built with Streamlit, Sarvam AI, and the MyMemory Translation API.

## Features
- Translate text between multiple languages
- Simple user interface
- Download translated text

## Technologies Used
- Python
- Streamlit
- Sarvam AI
- MyMemory API

## How to Run
Install the required packages:

```bash
py -m pip install streamlit sarvamai requests python-dotenv
```

Run the application:

```bash
py -m streamlit run app.py
```
