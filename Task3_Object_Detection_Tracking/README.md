# CodeAlpha Task 3: Object Detection and Tracking

A Python-based computer vision project that detects and tracks objects in a video using YOLO, OpenCV, and ByteTrack.

## Features
- Detects objects such as people, cars, and bicycles
- Draws bounding boxes and class labels
- Assigns tracking IDs across video frames
- Displays annotated video in a window

## Technologies
- Python
- Ultralytics YOLO
- OpenCV
- ByteTrack

## Setup

Install the required packages:

```bash
py -m pip install -r requirements.txt
```

Place a video named `input.mp4` in the project folder, then run:

```bash
py main.py
```

Press `Q` to close the video window.
